# PI-GINOT v1.0 — Step-by-Step Implementation Plan with Quality Gates

**Companion to:** `IMPLEMENTATION-v1.0-OSS.md` (strategy and rationale)
**This document:** the executable sequence. Nineteen steps, each with a gate that must
pass before the next step begins.

---

## 0. Gate policy

These rules apply to every gate in this document.

1. **`NOT_RUN` is never `PASS`.** A check that could not execute is recorded with a
   reason and blocks the gate unless explicitly marked optional in that step.
2. **Thresholds ratchet.** A numeric threshold may be tightened at any time. Loosening
   one requires an ADR in `docs/adr/` naming the measurement that justified it. Never
   loosen a threshold to make a failing implementation pass.
3. **Gates are sequential within a track.** Step N+1 does not begin until step N's
   gate passes. Declared parallel tracks (§1) are the only exception.
4. **Every gate produces an artifact.** `artifacts/gates/S<NN>.json` recording each
   check ID, status (`PASS` / `FAIL` / `ERROR` / `NOT_RUN`), measured value,
   threshold, and the execution profile it ran under.
5. **Anti-scope is checked, not assumed.** Each step lists what must *not* exist. A
   test enforces it.
6. **Coverage floors are per-module, not global.** The global floor is 80%; several
   modules are higher because they are pure logic with no excuse for gaps.

**Universal checks, run at every gate (`G-CODE`):**

```bash
ruff check .
ruff format --check .
mypy --strict src/
pytest --cov=src/piginot --cov-fail-under=<step floor>
pip-audit
```

Plus, from S0 onward:

```bash
pytest tests/test_no_fixture_names.py   # no dogbone/gauge/fillet/grip in src/
pytest tests/test_spike_isolation.py    # src/ has no import path into experiments/
```

### S1 — Risk spike ⚑ GO/NO-GO

**Objective:** measure achievable stress accuracy before investing in the framework.

**This is throwaway code.** It lives in `experiments/spike/`, is excluded from the
package, is never imported by `src/`, and every artifact it produces is permanently
tagged `LEGACY` and ineligible as release evidence.

**Deliverables**

- `experiments/spike/geometry.py` — analytic point/mesh generation for two families:
  parametric dogbone (4 parameters, as in the current repo) and a centre-notched
  plate (width, notch radius, notch depth).
- `experiments/spike/fem.py` — crude finite-strain plane-stress solver via
  `scikit-fem` or FEniCSx. Fixed fine mesh, no error estimator, no tag abstraction,
  no provenance. Correctness only.
- `experiments/spike/model.py` — the existing `physics_decoder` with a **second head
  for `P`** added. This is the first test of the mixed formulation.
- `experiments/spike/run.py` — solve, train hybrid, evaluate, emit
  `experiments/spike/results.json`.

**Protocol**

1. Generate 30 geometries per family. Solve all 60. Discard non-converged; if fewer
   than 50 converge, fix the solver before proceeding — that is itself a finding.
2. Split by geometry (never by node): 20 train, 10 evaluate, per family.
3. Train hybrid: FEM supervision on `u` and `P` plus the equilibrium residual on
   `P_served`. No tuning beyond a learning-rate sweep.
4. Report on the 10 held-out geometries per family.

**Gate `G1` — the decision rule**

| Check | Threshold |
|---|---|
| `G1.solves` | ≥50 of 60 FEM cases converged |
| `G1.sanity` | spike FEM reproduces uniaxial extension of a square to 1e-6 against closed form |
| `G1.split` | evaluation geometries share no nodes, meshes or seeds with training |
| `G1.report` | `results.json` contains, per family: relative L2 on `u`, relative L2 on `P`, worst-case error on peak notch/fillet stress |
| `G1.isolation` | `tests/test_spike_isolation.py` passes |

**Decision (human, not automated):**

| Measured `P` error | Action |
|---|---|
| ≤ 5% | **GO.** Proceed to S2 as planned. |
| 5–15% | **GO with contingency.** Proceed, and add a 3-week architecture iteration between S11 and S12. |
| > 15% | **STOP.** Do not build the framework. Iterate on architecture in the spike: weak-form residual, mesh-based encoder instead of point-cloud, deeper parameter conditioning, wider training set. Re-run `G1`. |

**Also record now, because it is cheap here and expensive later:**

- Does the peak notch/fillet stress QoI survive a regularity check, or is it singular?
  The notch root is the QoI users actually want and the one most at risk of rejection
  in S7.
- Wall-clock for one FEM solve vs one operator inference. This is your first
  `G-LATENCY` datapoint and your speedup story.

**Anti-scope:** nothing from the spike moves into `src/` by copy-paste. If a spike
module turns out to be good, it is *rewritten* under test in its proper step.

### S3 — Content store and retention

**Deliverables**

### S4 — Physics kernel and plane-stress closure

**Objective:** the constitutive kernel, correct to machine precision, differentiable
through the closure.

**Deliverables**

- `energy_density(F, mat)`, `first_piola(F, mat)`, `consistent_tangent(F, mat)` for
  compressible Neo-Hookean:
  `ψ = (μ/2)(tr(FᵀF) − 3) − μ ln J + (λ/2)(ln J)²`.
- `plane_stress_closure(F_2D, mat) -> F33` solving
  `g(F33) = μ(F33² − 1) + λ ln(J_2D) + λ ln(F33) = 0`
  by damped Newton, with a **custom autograd backward** using the implicit function
  theorem:
  `∂F33/∂F_2D = − λ F_2D⁻ᵀ / (2μ F33 + λ/F33)`.
- `admissibility(F, mat) -> bool` checking `J > margin`.
- Reference implementation `_closure_unrolled` (autodiff through Newton) kept in the
  test suite only, as the correctness oracle for the custom backward.

**Gate `G4`** — first real scientific gate

| Check | Threshold |
|---|---|
| `G4.stress-autodiff` | `P(F)` matches `∂ψ/∂F` to 1e-10 relative, 1000 random admissible `F` |
| `G4.tangent` | analytic tangent matches central differences to 1e-6 relative |
| `G4.objectivity` | `P(QF) = Q·P(F)` to 1e-12 for 100 random rotations |
| `G4.closure-residual` | `\|P33(F_3D)\| < 1e-10` after solve, 1000 random `F_2D` × `(E,ν)` across the admitted range |
| `G4.closure-unique` | Newton from 3 distinct starts converges to the same root within 1e-12 |
| `G4.ift-fd` | custom backward vs central differences, max relative error < 1e-6 |
| `G4.ift-oracle` | custom backward vs unrolled-Newton autodiff, agreement to 1e-8 |
| `G4.nu-zero` | at `ν = 0`: `F33 ≡ 1` and `∂F33/∂F_2D = 0` exactly |
| `G4.speed` | custom backward ≥3× faster than unrolled Newton on a 4000-point batch |
| `G4.coverage` | ≥95% on `piginot.physics` |

**Anti-scope:** no FEM assembly, no meshes, no ML.

### S8 — FEM verification: MMS and error estimation ⚑

**Objective:** establish that the primary solver is correct. This is the strongest
independence vector v1.0 has, and every accuracy claim downstream rests on it.

**Deliverables**

- Symbolically derived manufactured solutions (SymPy) covering: pure Dirichlet, mixed
  Dirichlet/traction, pure traction with body force, and a case with strongly varying
  `F33`.
- Patch tests, distorted-mesh tests, rigid-rotation objectivity, angular momentum,
  energy balance, reaction equilibrium, small-strain limit.
- Convergence study: ≥4 refinement levels, P1 and P2, for `u` in L2 and H1 and for
  `P` in L2.
- Richardson-extrapolation error estimator plus a recovery-based stress estimator,
  calibrated against known MMS error.
- Discretization cross-check (P1 vs P2, structured vs unstructured). **Named
  honestly:** this bounds discretization error, not implementation error.
- `IndependentSolverAdapter` protocol, shipped and documented, unimplemented in core.

**Gate `G8`**

| Check | Threshold |
|---|---|
| `G8.order-p1` | observed L2 order for `u` within 0.15 of 2.0, all four MMS cases |
| `G8.order-p2` | observed L2 order for `u` within 0.15 of 3.0, all four MMS cases |
| `G8.order-stress` | observed L2 order for `P` recorded and within 0.2 of theoretical |
| `G8.patch` | linear displacement field reproduced to 1e-12 |
| `G8.objectivity` | rigid rotation of a deformed state changes no invariant beyond 1e-10 |
| `G8.angular` | `‖skew(σ)‖ / ‖σ‖ < 1e-10` |
| `G8.energy` | `\|W_ext − W_int\| / W_int < 1e-8` |
| `G8.reaction` | `‖ΣR + ΣF_ext‖ / ‖F_ext‖ < 1e-9` |
| `G8.small-strain` | agreement with linear elasticity within 0.5% at 0.1% strain |
| `G8.estimator-brackets` | Richardson estimate brackets true MMS error in ≥95% of cases |
| `G8.estimator-conservative` | estimate ≥ true error in ≥90% of cases |
| `G8.seeded-defects` | six seeded defects (body-force sign, boundary normal, tag swap, closure wrong root, inconsistent tangent, anisotropic scaling) each fire ≥1 check |
| `G8.coverage` | ≥85% on `piginot.fem` |

### S12 — Objectives and gradient verification

**Deliverables**

- `DATA_ONLY`, `PHYSICS_ONLY`, `HYBRID` (default) objective registry, nondimensional.
- **Strong-form** equilibrium residual at collocation points (cheap, mesh-free) and
  **weak-form** Galerkin residual `∫ P : ∇δv − ∫ B·δv − ∫ T₀·δv` against element test
  functions. Weak form is the default for reported residuals and final refinement.
- `L_constitutive` **on in-plane components only.** The 33 component is identically
  zero by construction of the closure and the served embedding; including it dilutes
  the residual and turns a tautology into an apparent pass.
- `L_angular = ‖skew(P_served F_3Dᵀ)‖` reported as a separate first-class term.
- Finite-difference, reachability, detach and anisotropic-scaling harness.

**Gate `G12`**

| Check | Threshold |
|---|---|
| `G12.exact` | analytic exact-solution fixtures give residual < 1e-8 on every physics term |
| `G12.perturbed` | each perturbed fixture fires its named term and no other |
| `G12.fd` | finite-difference gradient check, max relative error < 1e-5, all terms |
| `G12.reachability` | every geometry, material, load and BC parameter reaches its loss path |
| `G12.anisotropy` | residual invariant under x-only coordinate scaling; `COORDINATE_ANISOTROPY` mutant fires |

### S14 — Verification, gates, envelope, confidence

**Deliverables**

- **Error budget** evaluated per coverage slice:
  `surrogate-to-FEM discrepancy + conservative discretization error + conservative
  projection error ≤ product tolerance`.
- Gate reducer over the twelve families. Any required `FAIL`, `ERROR` or `NOT_RUN`
  sets `NOT_VERIFIED`; no claim level attaches.
- Report includes required, passed, failed, errored, skipped and not-run sections —
  **the skipped and not-run sections appear even when empty.**
- Envelope checker: family membership, coupled bounds, topology and tag identity,
  query containment, adversarial guard-band refusal with stable reason codes.
- **Per-query confidence:** equilibrium and in-plane constitutive residual evaluated
  at query points, plus a calibration curve fitted on `DEVELOPMENT` mapping residual
  magnitude to observed error quantile.
- **`G-LATENCY`:** median and P99 inference latency and speedup vs primary FEM on an
  identical query set, single CPU thread.
- Holdout reveal path: consume, then evaluate. Consumption is recorded before reveal.

**Gate `G14`**

| Check | Threshold |
|---|---|
| `G14.budget` | budget arithmetic exact on synthetic cases with known components |
| `G14.reducer` | any required `FAIL`/`ERROR`/`NOT_RUN` yields `NOT_VERIFIED`, 100% of injected cases |
| `G14.report-sections` | a fully-passing run still emits skipped and not-run sections |
| `G14.refusal` | 100% refusal on a labelled OOD fixture set of ≥200 cases; ≤1% false refusal in-domain |
| `G14.reason-codes` | reason codes stable and identical across repeated runs |
| `G14.confidence` | Spearman correlation between residual indicator and observed error ≥0.6 on `DEVELOPMENT` |
| `G14.latency` | measured and reported; target ≥100× vs primary FEM (reported regardless of whether the target is met) |
| `G14.holdout-order` | consumption record durably precedes reveal; a crash mid-reveal cannot un-consume |
| `G14.no-certified` | the string `certified` appears nowhere in generated output |
| `G14.coverage` | ≥85% |

## 3. Gate result schema

```json
{
  "gate_id": "G4",
  "step": "S4",
  "commit": "<40-char sha>",
  "execution_profile_hash": "<hash>",
  "timestamp_utc": "2026-…",
  "checks": [
    { "id": "G4.ift-fd", "status": "PASS",
      "measured": 3.1e-7, "threshold": 1e-6, "comparison": "lte" },
    { "id": "G4.speed", "status": "NOT_RUN",
      "reason": "GPU unavailable in this environment" }
  ],
  "verdict": "FAIL",
  "verdict_reason": "1 required check NOT_RUN"
}
```

`verdict` is `PASS` only when every required check is `PASS`. Record the measured
value even on `PASS` — that is what makes the ratchet enforceable.
