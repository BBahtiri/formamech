# Benchmarks

One table per family, generated by `python -m campaigns.benchmarks table` from the committed campaign artifacts. Errors are relative; the TRAIN-rehearsal, DEVELOPMENT and HOLDOUT rows are the p90 over all cases of the S14 per-case budget (surrogate + FEM discretisation + projection), against the tolerances 5% (stress field), 5% (peak) and 2% (displacement). The Budget column is the status over every gated slice (all cases, and each stratum of each input), not only the all-cases numbers shown.

## Reproduction

`python -m campaigns.benchmarks reproduce --family F ...` replays the first 400 optimizer steps of the registered trial from its pinned seeds in a checkout of the training revision (interrupted and resumed at step 200) and compares the step-400 files with the registered run bit for bit; it then re-scores the frozen candidate on the TRAIN-screen cases and compares every TRAIN-screen metric with the table (relative tolerance 1e-09). DEVELOPMENT and HOLDOUT are not re-opened: HOLDOUT is consumed once, so its row is reported, not re-measured.

| --- | --- | --- |
| dogbone-v1 | True | True |
| notched-v1 | True | True |
